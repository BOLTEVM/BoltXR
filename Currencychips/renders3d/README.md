# Currencychips · renders3d

Real-time renders of the ten coins as built by `lib/coins` (the same code the XR wallet runs),
rendered headless (Chromium + SwiftShader WebGL). Nothing is painted or retouched. These are
not the concept images in the folder above.

## stills/ (1200 × 1200)

| File | What |
| --- | --- |
| `coin_<id>_front.jpg` | Obverse: emblem, bezel stones, engraved field and legend, halo above (SUI: its orbit ring) |
| `coin_<id>_34.jpg` | Three-quarter view: the relief, the reeded edge, the stones' fire |
| `coin_<id>_reverse.jpg` | Reverse: guilloché, the ticker raised in the centre, the legend |
| `contact_sheet.jpg` | All thirty |
| `vault_eight_coins.jpg` | The XR scene with eight held assets at headset quality: largest position in the middle, Bitcoin pointed at, Ethereum's balance just rising |

`<id>`: eth, btc, quai, pol, bnb, mon, sui, trx, bolt, sol.

## reels/

| File | What |
| --- | --- |
| `coins_vault.mp4` | 12 s, 1280 × 720, headset quality. Eight coins mint in (drop, spin, land with sparks), idle and flip; Bitcoin is pointed at; Ethereum's balance rises; Quai's network goes offline (red halo, wobble); Tron is sold and shrinks away. |
| `coins_turntable.mp4` | 7 s, 1280 × 720, hero quality. ETH, BTC, BOLT, POL and SUI turning, with balance-up sparks and a hover. |

The faces carry the ticker, the engraved network name and original emblems, not the
networks' official logos (see `docs/currency-coins.md`).
